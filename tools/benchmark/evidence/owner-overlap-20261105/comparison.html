Remaining copies, checks and limitations

RX packets are still copied into dispatch scratch; protected dispatch writes plaintext back to RX. The scratch remains live across child sends because parsed views borrow it while Engine is mutated. Blockwise response collection separately copies into a 4,098 B App hold before releasing the body slot.

Preallocation guarantees bounded capacity. It does not automatically overlay independent scratch or eliminate future captures. The next target is safe RX borrowing with split Engine access; a response hold replacement must preserve release timing and capacity.

924 alloc+oscore library tests passed; general independent source review found no actionable defect. The offline verifier reproduces the failed decision from 896 timing outputs and checks 1,916 archived members. No unchanged resampling, no changed acceptance rule, no fresh device or libcoap ranking.
