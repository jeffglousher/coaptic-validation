Coverage, fairness and interpretation
  • Three sizes (64/1,024/65,536 B), concurrency 1/4/16 and CON/NON; HTTP/3 uses warm/cold connections. Five complete rotated windows per stratum, seed 20261022, at least 60 seconds between same-stratum sessions, fresh server/cell. Operations/cell: 256/128/16 by size, one warmup per worker, one-second complete-operation deadline. Python adds one complete verified bootstrap GET per worker before warmup/timing. No measured cells are overwritten, retried or filtered.
  • Native Rust unprotected: Coaptic bare/reusable, coap-rs, libcoap, go-coap, aiocoap and the narrower coap-lite codec fixture. Matched Python unprotected repeats all seven; OSCORE covers Coaptic bare/reusable, aiocoap and libcoap. Common Go DTLS covers Coaptic/coap-rs test adapters and native go-coap/libcoap. HTTP/3 TLS1.3 remains a separate protocol.
  • Coaptic spins one UDP socket thread; coap-rs uses two Tokio workers; aiocoap uses asyncio; Go/runtime defaults are recorded. DTLS Coaptic uses one LocalSet thread and per-session Apps. Fixtures are not equally tuned and the codec endpoint is not a complete stack. Native and Python aiocoap server transports/ETags differ, so cross-stratum subtraction cannot isolate driver overhead.
  • OSCORE uses AES-CCM-16-64-128 / HKDF-SHA256, replay window 32 and fresh process-lifetime secret/salt. Shared driver sequence reservation and UDP dispatch are serialized. libcoap's authenticated Echo replay initialization completes outside timing. DTLS negotiates PSK/AES128-CCM8; handshakes precede timing. Crypto/client locking/runtime/ownership differ between strata; do not subtract these to claim isolated encryption cost.
  • coap-rs, go-coap and coap-lite have no OSCORE benchmark fixture. aiocoap and the codec fixture have no DTLS endpoint in this selected Windows build. Unsupported combinations are not encrypted successes. No EDHOC/enrollment, persistence, durable effects, restart recovery, Observe, loss or multicast costs are inferred.
  • Closed-loop complete GET goodput and RTT do not measure offered-load saturation or coordinated-omission-corrected latency. One outstanding operation/endpoint, no CoAP retransmission; endpoint rotation and byte verification are timed. All slower and failed observations remain in raw evidence.
  • Real sockets and complete observed outputs prevent trivial elimination in network tests. Socket-free probes additionally use std::hint::black_box, a best-effort optimization barrier, with raw clock calibration. Criterion was not added to the manual process/network harness. A compiler barrier is not a security/constant-time guarantee.
