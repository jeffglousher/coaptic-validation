Replace the App's implicit timestamp gate with an explicit EchoPolicy callback. It receives the parsed Echo (including malformed/absent values), peer address/port/scope, caller time and whether App verified OSCORE protection. It returns Accept, Challenge(opaque Echo), or Reject. Challenge/reject produces 4.01 before assembly/handler side effects; issuer failure can remain closed without inventing a challenge.

This is a pre-publication API change: migrate AppBuilder/App.echo_freshness(milliseconds) to echo_policy(callback). The caller owns issuance, bounded cache or authenticated construction, keys/entropy, expiry, endpoint/security-association binding and restart behavior. Timestamp helpers remain available as age classifiers and explicitly do not verify issuance. No dependency or allocation was added; the default no_std path remains dependency-free.
